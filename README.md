Experiments with performance engineering using Java, JDBC, PostgreSQL, and the Olist e-commerce dataset. Topics include measurement, database access, query plans, and performance trade-offs.

A local environment for studying event-driven architecture and Clean Architecture with PHP and Symfony, alongside PostgreSQL, Sqitch, and Kafka. The lab also explores separating framework-independent code from framework-specific runtime code.

A study developed during the IBM Bob bootcamp at DIO, exploring AI-assisted software development through a Python terminal interface and an MCP server. It includes experiments with agent instructions, architecture decisions, automated tests, and linting.
